# Mobile builds

The files below are the latest successful builds produced by GitHub Actions.

- **[Download Android APK](android/pixel-daylight-switch-debug.apk)** — install directly on an Android device. This is a debug build, not a Play Store release.
- **[Download iOS Simulator app](ios/pixel-daylight-switch-ios-simulator.zip)** — unsigned simulator app bundle. It cannot be installed on a physical iPhone or iPad.

Both files are regenerated after the Android and iOS build jobs succeed. The Android build is also checked on an emulator before the workflow finishes.
