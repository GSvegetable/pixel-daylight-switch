# Mobile builds

This directory contains the latest successful mobile builds produced by GitHub Actions.

- `android/pixel-daylight-switch-debug.apk`: Android debug APK. Install directly on Android; it is not a Play Store release build.
- `ios/pixel-daylight-switch-ios-simulator.zip`: unsigned iOS Simulator `.app` bundle. It cannot be installed on a physical iPhone or iPad.

Files are replaced automatically after both Android and iOS build jobs succeed.
