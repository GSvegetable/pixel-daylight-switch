# Mobile builds

Android and iOS build artifacts are generated by the [Native mobile builds workflow](https://github.com/GSvegetable/pixel-daylight-switch/actions/workflows/mobile-build.yml).

- Android: `pixel-daylight-switch-android-debug` workflow artifact (Debug APK; not a Play Store signing build).
- iOS: `pixel-daylight-switch-ios-simulator` workflow artifact (unsigned Simulator app; not installable on a physical iPhone or iPad).
- The workflow also runs an Android emulator runtime smoke test and publishes stable copies under this directory only after both native builds succeed.

Until a successful workflow has published the files, download the artifacts from the corresponding Actions run rather than assuming a binary exists in this directory.
